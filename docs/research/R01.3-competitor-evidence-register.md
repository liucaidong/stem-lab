## 1. 证据分级

| 等级 | 定义 | 使用方式 |
|---|---|---|
| E1 | 官方产品文档/帮助中心/开发者文档明确说明具体能力 | 可用于确认产品公开支持该能力 |
| E2 | 官方产品页/营销页明确宣称 | 可记录为厂商宣称；效果和边界仍需独立验证 |
| E3 | 官方案例、官方课程或官方生态页间接支持 | 仅用于佐证应用场景 |
| E4 | 第三方资料、用户反馈或媒体报道 | 辅助参考，不能替代官方证据 |
| I | 分析推断 | 必须标明为推断，不得写成事实 |

证据等级衡量的是“当前主张被来源支持的程度”，不代表产品质量排名。

## 3. 数字口径与注意事项

| 产品 | 官网数字 | 风险/备注 |
|---|---|---|
| Labster | 300+ simulations | 官网营销页数字，未独立盘点 |
| PhET | 173 simulations（当前官网动态值） | 数字可能随新增模拟变化 |
| Beyond Labz | 499 university + 234 high school；另称 650+ | 499+234=733，与“650+”不一致；不得自行推断去重或统计口径 |
| PraxiLabs | 首页 210+；旧/另一功能页曾列 20 项免费实验 | 210+ 为完整目录口径；20 项是免费计划口径，不冲突 |
| Gizmos | 不在本批次确认固定数量 | 历史网页存在 400+/500+ 不同表述，未完成时间与口径核实，不在矩阵写死 |

## 4. 尚未取得的证据

以下项目目前标记为“未确认”，不是“不支持”：
- 竞品内部是否有独立 Model Engine、Runtime、Scheduler 或统一事件模型；
- 是否开放第三方插件、模型 SDK 或稳定公共 API；
- 是否支持完整离线运行、私有化部署和数据驻留；
- 是否提供 LTI 1.3、SCORM、xAPI 的完整兼容矩阵；
- VR/AR 设备兼容性、空间交互和性能要求；
- 科学求解器的数值方法、误差控制、验证基准与可复现性；
- AI 功能的工具调用权限、可审计轨迹、验证器与安全边界。

## 5. 引用与更新规则

- 每次更新记录查阅日期、URL、页面标题和主张。
- 页面动态数字需标记“官网当前显示”，不得长期当作固定事实。
- 对产品能力的强主张，尽量同时引用产品文档与实际试用证据。
- 如果官网营销页与帮助文档口径冲突，优先记录冲突，不擅自选择更大的数字。
