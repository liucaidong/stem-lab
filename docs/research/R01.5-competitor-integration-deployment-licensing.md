## 1. 核心补证结论

| 产品 | 已核实的集成/部署能力 | 对本项目的启示 |
|---|---|---|
| Labster | 官方 LMS Admin 文档列出 Canvas、Blackboard、Moodle、D2L/Brightspace、Sakai、Schoology，并有 LTI 1.3 配置流程及 Canvas API 配置指南 | LMS 接入优先研究 LTI 1.3，并区分 Launch、成绩回传、Roster/SSO |
| ExploreLearning | OneRoster v1.1、LTI v1.0/1.1/1.3、SAML、Clever Roster、ClassLink API；OneRoster 通过 SFTP 文件同步 | 学校集成需要 Roster/SIS，不只是课程链接 |
| SimScale | Simulation API 支持上传几何、配置研究、启动仿真、参数扫描、取回结果；官方 SDK 有 Python/C# | 计算后端应有完整作业生命周期 API，支持自动化调用 |
| GeoGebra | Apps Embedding、JavaScript Apps API；支持状态读写、监听对象变化、导出；提供 Math Apps Bundle 自托管方案 | 外部学科工具需支持双向状态桥接、事件和版本管理 |
| Tinkercad | Classrooms 支持教师发送/接收作业、查看学生进度、分配活动、共同教师协作 | 创作工具必须连同课堂、作品和教师权限设计 |
| Minecraft Education | 官方列出教育/商业年度许可价格、设备要求、最多 30 人协作和 Portfolio | 机构授权、设备部署、班级协作和作品证据需纳入产品方案 |
| SimScale Academic | 免费 Academic Plan 有 2,000 core hours；学生计划 12 个月，教师/研究人员评估计划 3 个月；部分 solver 不包含 | 教育版计算成本可用配额管理，但须明确 solver 和用途限制 |
| Ansys Student | 免费学生版限教育用途；Windows 10/11 64-bit；网格/节点规模、GPU、HPC 等有限制 | 免费不等于无约束，许可边界和运行规模必须进入竞品评估 |

## 2. 重点产品事实

### 2.1 Labster：LTI 1.3 与 LMS 管理

官方帮助中心提供 LMS Admin 集成说明，列出 Canvas、Blackboard/Blackboard Ultra、Moodle、D2L/Brightspace、Sakai、Schoology，并有 LTI 1.3 配置步骤。另有 Canvas API 配置说明。

来源：
- [LMS Integration for LMS Admin](https://help.labster.com/en/collections/3094279-lms-integration-for-lms-admin)
- [The Educator's Guide to Labster](https://www.labster.com/guides/the-educators-guide-to-labster)

判断：Labster 的 LMS 能力有明确官方文档支撑。当前资料不能据此推断它提供任意实验内容 API 或开放模型 SDK。

### 2.2 ExploreLearning：Roster/SIS 集成

官方支持 OneRoster Standard（LTI v1.0、v1.1、v1.3 或 SAML）、Clever Roster、ClassLink API。OneRoster 数据通过 SFTP 文件同步，可自动创建账户并进行夜间更新。

来源：
- [Rostering Integrations Offered](https://help.explorelearning.com/en/articles/9000790-rostering-integrations-offered)
- [OneRoster File Structure](https://help.explorelearning.com/en/articles/9000284-oneroster-file-structure)

判断：LMS、SSO、Roster/SIS、成绩回传应作为不同能力项建模。

### 2.3 SimScale：完整仿真生命周期 API

官方 Simulation API 页面说明支持上传 CAD 几何、配置 simulation studies、启动分析、自动参数扫描、访问仿真结果和获取后处理图像/视频；官方 SDK 提供 Python 与 C#，REST API 可由其它语言调用。页面也描述 CI/CD 与 Agent-driven workflows。

来源：
- [SimScale Simulation API](https://www.simscale.com/technology/simulation-api/)

判断：SimScale 是“计算服务 API + 工作流编排 + AI Agent 调用”的重要技术参照，但其专业工程仿真能力不等价于 K–12 教学模型运行时。

### 2.4 SimScale Academic：计算配额

官方 Academic Program 页面列出：
- 学生论文/毕业设计：12 个月、2,000 core hours；
- 教师评估：3 个月、2,000 core hours；
- 学术研究人员评估：3 个月、2,000 core hours；
- LBM、Multi-purpose、PWC solver 不在免费 Academic Plan 中；
- 纯学术用途限制；平台支持 Mac、PC、Linux、Chromebook。

来源：[SimScale Academic Program](https://www.simscale.com/academic-program/)

判断：云仿真教育版可以采用计算时长配额，但必须定义计量、资格、solver 覆盖和用途限制。

### 2.5 GeoGebra：嵌入 API 与自托管

官方文档明确：
- 可通过 deployggb.js 嵌入 Geometry、Graphing、3D 等 App；
- 可加载指定 material；
- JavaScript Apps API 支持命令执行、状态读写、对象增删监听；
- 支持 PNG/SVG/PDF 等导出；
- 提供 Math Apps Bundle，可下载后自行托管；
- 可固定具体版本的 HTML5 Codebase。

来源：
- [GeoGebra Apps Embedding](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_Embedding/)
- [GeoGebra Apps API](https://geogebra.github.io/docs/reference/en/GeoGebra_Apps_API/)
- [Material Embedding](https://geogebra.github.io/docs/reference/en/Material_Embedding_%28Iframe%29/)

判断：GeoGebra 是“嵌入式学科计算 App + 双向 API + 可自托管资源”的强参照；其 API 不是通用 STEM 实验模型协议。

### 2.6 Tinkercad：课堂与作品工作流

Autodesk 官方资料说明 Tinkercad Classrooms 支持教师发送/接收作业、监控学生进度、分配活动、邀请共同教师、审阅学生作品，并可通过 Safe Mode 限制公开分享和内容干扰。

来源：
- [Tinkercad Getting Started Guide](https://damassets.autodesk.net/content/dam/autodesk/www/pdfs/tinkercad-getting-started-guide.pdf)
- [Tinkercad Classrooms Printable Guide](https://images.tinkercad.com/jl5ii4oqrdmc/5v197WuuaqspGT81cG5tT6/81154785a527f1b42a32325487a30e44/tinkercad-guides_classrooms-Printable.pdf)

判断：创作系统应同时考虑学生作品、课堂活动、教师管理和安全分享设置。

### 2.7 Minecraft Education：许可、协作与设备边界

官方许可页当前列出：
- 合格教育机构直接购买：$5.04 / user / year（年度承诺）；
- 商业组织：$36 / user / year（年度承诺）；
- 最多 30 名学生在一个活动中协作；
- Camera 与 Portfolio 用于学习证据收集；
- Windows、Mac、Chromebook、iOS/iPadOS、Android 等最低系统要求；
- 超过 600 项标准对齐课程为官网当前显示的宣传数字。

来源：
- [Minecraft Education Licensing](https://education.minecraft.net/en-us/licensing)
- [Minecraft Education Getting Started](https://edusupport.minecraft.net/hc/en-us/articles/360047557271-Getting-started-with-minecraft-education)

判断：Minecraft Education 是课堂协作、空间创作、作品证据和机构授权的参照，不是科学数值仿真引擎。

### 2.8 Ansys Student：免费许可的适用范围

Ansys 官方学生版页面说明：免费学生软件仅供教育用途；支持 Windows 10/11 64-bit；Discovery 需要专用 NVIDIA GPU；结构、流体等求解规模以及 HPC 资源存在限制；学生版本有许可期限。

来源：[Ansys Student](https://www.ansys.com/en-in/academic/students/ansys-student)

判断：学生版适合学习专业工作流，但不能视为生产级无约束授权。

## 4. 对平台架构的直接影响

1. Integration Layer 应拆分协议：LTI 1.3、OneRoster、SAML/OIDC、成绩回传、Roster/SIS、内容嵌入 API、仿真执行 API、设备协议分别建模。
2. Experiment Runtime API 与 LMS API 分离：LMS 负责课程、身份、作业入口与成绩交换；Runtime API 负责实验 Session、状态、命令、观测和结果。
3. 外部工具采用 Adapter：GeoGebra、SimScale 等通过适配器接入，不把厂商内部 API 直接变成平台核心领域模型。
4. 内容和执行协议分离：一个实验包可关联多个工具/求解器，但不绑定某一厂商 UI。
5. 部署模型应多档：SaaS、多租户、机构独立空间、自托管内容资产、边缘设备/本地 Worker 应分别分析。
6. 许可元数据应进入集成评估：第三方内容、求解器和嵌入工具需记录许可范围、配额、数据处理条款和再分发限制。

## 5. 未解决问题

- Labster、PraxiLabs 的成绩回传字段与 LTI Advantage 服务支持范围需逐项核验。
- SimScale API 的速率限制、认证、异步任务状态机、数据保留和商业许可条款需继续核实。
- GeoGebra Bundle 的再分发、品牌、内容许可和商业使用限制需法律审查。
- Tinkercad 第三方自动化 API 支持未确认。
- Minecraft Education 的本地/离线能力、服务端扩展接口、数据导出边界未完成核验。
- Ansys Student 不能代表 Ansys Teaching/Research/Campus 产品授权和限制。
