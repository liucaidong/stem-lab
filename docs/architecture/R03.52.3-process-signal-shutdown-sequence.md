# R03.52.3 Process Signal & Shutdown Sequence

- Status: Reference protocol diagram.

```mermaid
sequenceDiagram
  participant OS as Operating System
  participant SH as Signal Handler
  participant M as Monitor Thread
  participant P as WorkerPool
  participant W as WorkerRuntime
  OS->>SH: SIGTERM / SIGINT
  SH->>SH: set shutdown-requested Event only
  M->>M: observe Event
  M->>P: request_shutdown()
  P->>W: request_shutdown() for every poller
  W->>W: stop new claims; drain active handler
  W->>W: continue lease heartbeat during drain
  W-->>P: poller exits
  P-->>OS: process run returns
```

If the deployment deadline expires, the external supervisor may terminate the process. It must not fabricate job completion or lease release; database lease expiry and fencing recover ownership.
