# R03.34 Package Resource Graph 与 Dependency Closure

- 版本：0.1；日期：2026-11-02
- 状态：CI Run #90通过静态Graph验证（局部）；未接入生产Package发布器/资源仓库
- 关联：R03.8、R03.17、R03.20 DEC-27/28/29、R03.30、R03.31、R03.33

## 1. 目标与边界

将Package的Model、Scene、Instrument、Workflow、Rubric、Asset及其传递依赖建模为有向资源图。验证器负责结构、身份、引用完整性、环检测、根节点可达闭包和资源访问策略；不下载外部资源、不执行资源、不计算Package Digest、不验证签名或License。

## 2. 资源身份与类型

资源逻辑身份由(resource_type, resource_id, version)组成，内容身份由digest绑定。相同逻辑身份不得对应不同digest；同一节点可被多个父节点引用，但图中只允许一个节点定义。相同资源的多条不同关系边可存在，完全相同的边拒绝。

资源类型枚举：package、model、scene、instrument、workflow、rubric、asset、dataset、solver-profile、other。资源ID不承载路径或下载权限语义。

## 3. 图结构

- root_resource_id：唯一Package根资源。
- nodes：每个资源一个节点，包含resource_id/type/version/digest/storage。
- edges：from/to/relation，relation为requires、embeds、uses、references。
- policy：外部主机allowlist与受限引用策略。

所有边必须引用已声明节点；所有节点必须从root可达；所有依赖环拒绝。闭包是从根沿全部边可达的节点集合，闭包之外的孤儿节点拒绝。

## 4. 资源位置和安全策略

| storage | 语义 | 校验 |
|---|---|---|
| embedded | Package内容树内的相对路径资源 | POSIX相对路径；拒绝绝对路径、盘符、反斜线、..路径段 |
| external | 外部HTTPS内容寻址资源 | 必须HTTPS、主机在显式allowlist、digest固定；静态验证器不发起网络请求 |
| restricted | 受访问策略保护的资源 | 必须access_policy_id；仅在Package策略显式允许时可进入引用图；实际授权在运行时重新执行 |

外部资源主机allowlist不是SSRF防护的充分条件。实际抓取必须由隔离发布服务执行DNS/IP解析、重定向限制、私网地址拒绝、超时/大小/MIME限制和内容Digest验证。Runtime不按Package URI直接抓取资源。

## 5. 完整性规则

1. resource_id在Graph内唯一。
2. (resource_type, resource_id, version)只能绑定一个digest。
3. digest格式为sha256: + 64位小写hex；字节真实性由R03.30资产层验证。
4. 所有edge.from/to必须解析到节点。
5. 禁止重复完全相同的边。
6. 图必须无环；依赖升级不得形成循环。
7. 所有nodes必须属于root dependency closure。
8. 相同资源被多角色引用时复用同一节点，不复制节点。
9. Graph节点的digest、版本和类型必须与Package Manifest中引用字段一致；当前Manifest到Graph映射集成尚未实现。

## 6. Schema与Fixtures

- Schema：contracts/package-resource-graph.schema.v1alpha1.json
- Fixture：contracts/examples/package-resource-graph.fixtures.v1alpha1.json
- 验证器：scripts/validate_package_resource_graph.py

正向图覆盖Package根及Model、Scene、双Instrument、Workflow、Rubric和Asset。负向案例覆盖悬空引用、重复节点、同身份不同Digest、依赖循环、闭包外孤儿、未授权外部主机、不安全嵌入路径、缺少restricted policy和策略禁止restricted reference。

## 7. 不变量与后续集成

Package Manifest的当前ResourceRef字段没有resource_type/location或显式dependency列表；角色字段隐含部分类型语义。集成层必须将固定角色映射到节点类型，并从资源元数据提取传递依赖。不可将R03.34 Graph Schema与现有Package Schema混同，也不可在没有内容索引时假称已完成全量依赖闭包。
