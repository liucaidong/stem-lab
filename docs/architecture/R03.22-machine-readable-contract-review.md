## 4. 草案中已知限制

1. Package Schema的$id使用example.invalid占位域名，正式发布前必须替换为受控Schema URI。
2. 当前Schema没有实现跨字段约束，例如gradeBand.min不得大于gradeBand.max。
3. digest正则只验证字符串形态，不验证真实内容摘要。
4. Package依赖引用存在性、许可合法性、签名和科学正确性属于Schema之外的语义校验。
5. Event Envelope Schema只定义通用信封，不包含每一种event_type对应的payload schema。
6. OpenAPI草案的若干响应只有description，没有完整Schema；尚不满足代码生成和生产互操作要求。
7. OpenAPI的security、错误响应、限流、分页和资源级权限仍需逐端点补齐。
8. 当前样例ID、摘要和服务器地址均为合成占位值。
