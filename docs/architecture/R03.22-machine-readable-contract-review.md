## 3. 尚存问题

1. Package Schema 的 `$id` 仍为 `example.invalid` 占位地址。
2. `gradeBand.min <= gradeBand.max` 跨字段约束尚未实现。
3. Digest 规则只检查格式，不验证实际资源字节摘要。
4. 依赖引用存在性、签名、许可策略、撤回状态和科学正确性需要语义校验器及治理流程。
5. Event Schema 只有通用信封，缺少各 event_type 的 payload schema。
6. OpenAPI 多个响应仅有 description，缺少完整响应 Schema；统一错误模型、资源级授权、分页、限流等尚未完整。
7. 一次性本地验证尚未取得仓库CI成功运行证据；验证脚本、固定依赖和GitHub Actions工作流已提交。
8. OpenAPI Draft已扩展至0.2，增加响应/错误Schema；该次修订尚未重新执行YAML解析和OpenAPI 3.1规范验证。
