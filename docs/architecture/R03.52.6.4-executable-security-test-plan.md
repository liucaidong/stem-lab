# R03.52.6.4 — Executable Security Test Plan

- Status: partial executable harness; not production security certification
- CI target: PostgreSQL 17 service already present in contract-validation workflow

## 1. Tests added

| Test | Environment | Purpose | Evidence class |
|---|---|---|---|
| Signed tenant assertion negative/positive tests | Python stdlib | Signature, tamper, expiry, audience, action and job binding | Reference contract only |
| Missing GUC | Real PostgreSQL 17 | RLS returns zero rows and denies writes without context | VERIFIED when CI passes |
| GUC spoof | Real PostgreSQL 17 | Demonstrate app role can set custom GUC and cross tenant under GUC-only policy | Expected vulnerability demonstration |
| Commit cleanup / pooled connection reuse | Real PostgreSQL 17 | Transaction-local context absent in next transaction | VERIFIED when CI passes |
| Rollback cleanup | Real PostgreSQL 17 | Failed transaction does not leak context | VERIFIED when CI passes |
| Concurrent tenant sessions | Real PostgreSQL 17 | Separate transactions see only their own rows | VERIFIED when CI passes |

## 2. Required but not yet implemented

- API principal/JWT issuer/audience/JWKS and membership binding tests.
- Tenant selector spoof at API boundary.
- Signed assertion verification inside PostgreSQL or an independently trusted DB gateway.
- Assertion expiry/replay/nonce and signing-key rotation.
- Job payload tenant mismatch against persisted row.
- Cross-tenant claim, renew, complete and fail against a production Store adapter.
- DLQ replay authorization + Job/DLQ/audit atomic persistence.
- Pool cancellation, broken connection discard, pool exhaustion and server failover.
- SECURITY DEFINER and runtime/migration/admin grant audit.
- Multi-process worker restart and fencing fault injection.

## 3. Execution

CI invokes `python scripts/test_tenant_context.py` and `python scripts/test_tenant_rls_trust_boundary_postgres.py` after PostgreSQL 17 service health is established. A green run verifies only the stated disposable harness and reference contract. It does not close DEC-19 or DEC-04.
