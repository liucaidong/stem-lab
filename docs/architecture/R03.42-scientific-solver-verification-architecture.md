# R03.42 Scientific Solver Verification Architecture

- 版本：0.1；日期：2026-11-02
- 状态：CI Run #143通过DC/RC test-only数值参考Harness（局部）；生产Solver选择DEC-10保持OPEN
- 关联：R03.9、R03.24、R03.29、R03.33、R03.41

## 1. Solver Adapter Contract

Solver输入必须包含Model/Equation版本、Quantity Type/Unit Registry版本、初始状态、参数、Simulation Time区间、精度容差、步长策略、资源Quota和确定性策略。输出包含状态轨迹、误差估计、步长统计、终止原因、Solver版本和输入Digest。

Solver职责仅为科学数值计算；Runtime负责调度/取消/Lease/Checkpoint；Model定义方程和边界条件；Observation负责记录量值、单位、仿真时间、墙钟时间、来源与质量标记。

## 2. ODE Contract

- State vector必须有稳定变量顺序和Quantity Type；
- Time必须携带单位；求解器内部时间单位转换需显式且可审计；
- 支持固定步长与自适应步长接口；自适应算法需声明误差估计器；
- 定义绝对/相对容差、最小/最大步长、最大步数；
- 记录accepted/rejected steps、局部误差估计和终止条件；
- 非有限值、溢出、非法状态、步长下溢必须失败终止，不得写入成功Observation。

## 3. Numerical Accuracy / Stability / Convergence

使用解析Reference Solution、守恒律/不变量、维度规则和网格加密测试联合验证。收敛阶通过步长减半误差比估计；稳定性通过已知稳定区间、刚性案例和步长敏感性评估。单次结果接近解析值不能证明稳定/收敛。

DC系列电路作为代数平衡Reference：欧姆定律、KVL和功率平衡。RC充电作为ODE Reference：dVc/dt=(Vs−Vc)/(R×C)，tau=R×C，Vc(t)=Vs(1−exp(−t/tau))。本阶段使用Euler/RK4仅作为测试参考积分器，验证阶数和误差趋势，不作为生产Solver选型。

## 4. Error Estimation / Step Control

候选策略：Embedded Runge-Kutta pair、Step Doubling、Residual-based估计。Solver必须输出误差估计及接受/拒绝步数；控制器按容差调整步长并满足min/max bounds。具体算法与参数由DEC-10 Spike决定。

## 5. Determinism / Replay

确定性声明必须限定平台、浮点格式、数学库、并行归约顺序、随机种子、Solver版本和编译参数。跨平台bitwise equality与tolerance-based numerical equivalence是不同等级，不得混称。Runtime Replay需固定输入Digest、Unit Registry版本、Solver版本和执行配置。

## 6. Verification Assets

- contracts/solver-verification-contract.schema.v1alpha1.json；
- contracts/examples/solver-verification.fixtures.v1alpha1.json；
- scripts/test_solver_numerical_reference.py。

脚本执行DC平衡、RC解析Reference、Euler/RK4步长收敛、稳定性/单调性、重复确定性和量纲传播检查。参考算法只存在于测试脚本。

## 7. Not Tested

生产Solver接口/插件、刚性ODE、多变量耦合、事件定位、DAE/PDE、随机系统、Adaptive Step Controller、跨平台回归、Checkpoint/Resume、Solver性能、浮点边界、科学专家签核和真实模型求解。
