## 3. 内容寻址和Digest范围

R03.8定义Package Digest应覆盖规范化Manifest和全部依赖内容。实现前必须明确：
- JSON/YAML规范化规则（键顺序、Unicode、换行、数值表示、空字段）；
- 文件路径规范化与排序；
- 是否包含目录名、文件模式、媒体类型、许可和来源元数据；
- Digest算法版本与前缀；
- 子资源digest与顶层Package digest的层级关系；
- symlink、hardlink、压缩包条目、重复路径和大小写冲突的处理；
- 不可变发布版本与撤回记录的关系。

不得把当前单Asset的SHA-256校验等同于Package完整性摘要。

## 4. 安全边界

- 所有Package/Asset元数据均为不可信输入；
- 本地路径必须限制在受控根目录，禁止绝对路径、父目录跳转和符号链接逃逸；
- 远程资源应在发布前下载到隔离区、校验内容、扫描许可与安全后再转为内容寻址资源；
- Runtime不得按Package提供的任意URL动态拉取资源；
- 不执行Package内Shell/Python/JavaScript；
- 资源解压必须限制文件数、总解压大小、压缩比、嵌套深度和CPU/内存；
- 媒体类型不得只信任扩展名或声明MIME；
- License/Provenance必须与内容版本一起锁定。
