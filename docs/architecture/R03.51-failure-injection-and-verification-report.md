| Case | Expected |
|---|---|
| single worker claim | one owner, expiry and epoch 1 |
| two concurrent workers / one Job | exactly one claim |

| expired completion before reclaim | rejected |

| retryable failure | durable retry, attempts retained |
| non-retryable failure | DLQ record and terminal Job |
| maximum attempts | no further retry |
| duplicate completion | no second effect |
| tenant RLS | cross-tenant Job rows invisible |
