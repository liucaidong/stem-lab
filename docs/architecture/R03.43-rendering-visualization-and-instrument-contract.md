# R03.43 Rendering、Visualization 与 Instrument Contract

- 版本：0.1；日期：2026-11-02
- 状态：Renderer/Scene/Timeline/Instrument契约草案；未实现Renderer Adapter
- 关联：R03.9、R03.24、R03.29、R03.41、R03.42

## 1. 职责边界

Scientific Model定义物理状态/方程；Solver生成数值结果；Runtime控制Execution/Simulation Time/Observation采样；Renderer只消费Scene/Observation并绘制；Instrument Adapter把Observation映射为仪表读数；Interaction只发出Command，不直接修改权威Scientific Model或Session状态。

Renderer不得拥有科学真值，不得在渲染帧率上推进求解器，不得将动画时间伪装成Simulation Time。

## 2. Renderer Adapter

Adapter声明renderer_id/version、2D/3D能力、Scene Graph/Camera/Animation/Interaction/Instrument Overlay能力。上层Visualization Contract不依赖具体引擎。Renderer资源和材质不作为科学模型参数。

## 3. Scene Graph与Coordinate System

Scene Graph是有根树，node_id唯一；parent必须存在；禁止循环。节点类型包含root/group/mesh/line/label/sprite/instrument-anchor。Transform使用明确约定的4×4矩阵；矩阵列/行主序、乘法顺序、局部/世界坐标转换需在Renderer Adapter Profile进一步固定。

Coordinate System必须声明handedness、up_axis、length_unit和origin。不同Renderer Adapter之间必须显式转换，不允许隐式交换轴或单位。

## 4. Timeline与Time Synchronization

Timeline必须声明time_domain为simulation或wall-clock，单条Timeline不允许混合。Simulation timeline由Runtime时间推进驱动；wall-clock timeline只用于UI过渡/非科学动画。渲染掉帧不得改变Observation时间戳或Solver步长。跨时钟同步需定义pause、seek、reset和late frame行为。

## 5. Interaction Contract

交互命中场景对象后生成Command/Intent，携带目标资源引用和预期stateVersion；Runtime Command Handler负责授权、状态迁移和幂等。Renderer不得直接写Model变量。拖拽、连线、参数调节需映射为类型化Command。

## 6. Instrument Contract

Instrument声明instrument_type、node_id、quantity_kind、unit_id、sampling_interval、measurement_range和Observation Binding。读数来源必须为Observation，标注source_type=instrument；单位转换使用Quantity/Unit Registry，超量程应标记质量状态而不是静默截断。仪表采样时刻必须绑定Simulation Time，observed_at记录Wall-clock Time。

## 7. 自动化资产

- contracts/visualization-instrument-contract.schema.v1alpha1.json；
- contracts/examples/visualization-instrument.fixtures.v1alpha1.json；
- scripts/validate_visualization_instrument_contract.py。

静态验证覆盖Scene Graph唯一性/父节点/环、Timeline目标/范围、Instrument Node/Unit Binding/Range/Sampling和10个负向案例。它不运行Renderer或真实仪表。

## 8. Not Tested

2D/3D Renderer Adapter、GPU/浏览器兼容、相机投影、坐标矩阵数值转换、材质/动画性能、真实Interaction到Command链路、Observation采样同步、仪表误差/精度/延迟、渲染帧率与Simulation Time一致性。
