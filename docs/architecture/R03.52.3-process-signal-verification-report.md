## 4. What this proves

The reference bridge installs handlers on the main thread, keeps signal callbacks minimal (Event set only), forwards shutdown from a monitor thread, and restores previous handlers. It does not mutate Job state or release leases.

## 5. What this does not prove

- No real SIGTERM/SIGINT delivery test against a running container or host process.
- No Kubernetes/systemd/container restart or termination-grace integration.
- No hard cancellation of non-cooperative handlers or bounded shutdown guarantee.
- No production Store adapter, trusted tenant context, Broker relay, telemetry or health endpoint.
- No production process supervision or restart/backoff policy.
