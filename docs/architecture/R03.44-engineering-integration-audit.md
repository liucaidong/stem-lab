## 2. 已修复的一致性问题

### AUD-FIX-01：Expression Language与AST Schema版本映射

ScientificModel的expressionLanguage是stemlab-expression-ast/v1，而AST Schema ast_version是1alpha1。此前没有显式映射字段。现增加AST language_id并与Model Contract常量一致；ast_version继续表示具体序列化Schema版本。

### AUD-FIX-02：Expression Resource Graph类型缺失

ScientificModel的equations通过expressionRef引用独立表达式资源，而Resource Graph此前没有expression类型。现增加expression资源类型，并在正向Graph Fixture中加入Model→Expression依赖边。真实Package/Model自动投影仍未实现。

### AUD-FIX-03：Runtime Execution状态集合漂移

R03.41曾将starting/checkpointing/cancelling与权威Execution状态混在一起，偏离R03.15状态矩阵。现将Schema枚举对齐R03.15；这些阶段保留为Worker内部phase，不新增持久化Execution状态。

### AUD-FIX-04：NaN/Infinity负向测试证据不足

此前JSON Fixture中的Infinity经JSON序列化变成null，不能证明解析器拒绝NaN/Infinity。现增加对NaN、Infinity、-Infinity JSON token的直接解析拒绝测试。

### AUD-FIX-05：CI Push Path遗漏锁文件

已将requirements-contract-validation.lock.txt加入push触发路径，避免锁文件单独变更时漏跑CI。
