# R03.29 单位、量纲与科学量值契约草案

- 版本：0.1；日期：2026-11-02
- 状态：技术无关的核心SI单位/量纲候选；未选择第三方单位库，未冻结转换策略
- 关联：R03.9、R03.20 DEC-08/DEC-17、R03.23、R03.24、R03.25、R03.28

## 1. 目标与边界

本文件定义ScientificModel、Observation和参考算例需要的最小单位语义，以避免仅比较任意字符串。它是可验证的核心单位登记草案，不是完整的SI单位系统，也不代表已选定Pint、Astropy、UDUNITS或其他单位库。

本版覆盖DC/RC验证所需的V、A、ohm、W、F、s和dimensionless。暂不覆盖前缀单位、非SI单位、温度偏移单位、复合单位表达式、测量不确定度单位换算和用户自定义单位。

## 2. 量纲向量

维度顺序固定为：

`[mass, length, time, electric_current]`

每个分量为相对于SI基本维度的整数指数：
- V：`[1, 2, -3, -1]`
- A：`[0, 0, 0, 1]`
- ohm：`[1, 2, -3, -2]`
- W：`[1, 2, -3, 0]`
- F：`[-1, -2, 4, 2]`
- s：`[0, 0, 1, 0]`
- dimensionless：`[0, 0, 0, 0]`

维度向量是机器可比的物理量维度，不是教学展示字符串。

## 3. Unit Registry结构

- `unit_id`：契约内部稳定标识，Model/Observation引用；
- `symbol`：显示符号；
- `name`：英文规范名称；
- `quantity_kinds`：允许的物理量类别；
- `dimension`：四维整数指数；
- `scale_to_si`：换算至对应SI单位的正比例因子；
- `offset_to_si`：偏移量，本版全部为0。

文件：
- `contracts/units/unit-registry.schema.v1.json`
- `contracts/units/si-unit-registry.v1.json`

## 4. 核心语义规则

1. Model参数、变量和Observation必须引用Registry中存在的unit_id。
2. Model的quantityKind必须属于该unit的quantity_kinds。
3. Observation的quantityId必须指向Model变量，且unit必须与变量的单位兼容；本版先要求完全相同的unit_id，不做隐式换算。
4. 数值计算内部是否全部转换到SI、是否允许非SI输入，在DEC-08/DEC-17中继续决策。
5. 不同量纲禁止相加、比较或赋值；乘除运算按指数向量逐维相加/相减。
6. 三角、指数、对数等函数的输入量纲约束必须由表达式AST/类型检查器定义，不能只依赖运行时浮点值。
7. 维度一致不代表物理语义正确；例如不同quantityKind可能共享同一dimension，仍需语义类型系统区分。
8. `scale_to_si`必须有限且大于0；`offset_to_si`必须有限。非零offset单位会影响乘除运算，本版不纳入。

## 5. 科学模型和参考算例映射

| 物理量 | quantityKind | unit_id |
|---|---|---|
| Source Voltage / Voltage Drop | electric-potential | V |
| Current | electric-current | A |
| Resistance / Equivalent Resistance | electric-resistance | ohm |
| Power | power | W |
| Capacitance | capacitance | F |
| Simulation Time / Time Constant | time | s |

## 7. 未决决策

- DEC-08：第三方单位库、单位转换和运行时集成；
- DEC-17：double precision/numeric/双表示及序列化精度；
- Model Expression AST如何携带quantityKind和dimension；
- 用户自定义单位、国际化符号和本地化显示；
- 仪器精度、有效数字和不确定度传播；
- SI定义更新和Registry版本兼容策略。

## 8. 当前结论

本草案把DC/RC核心单位从自由字符串推进为可版本化的Registry和量纲向量。它尚未实现完整单位运算、转换或Solver量纲推导，也未获学科专家签核。W1.5保持IN PROGRESS，DEC-08/DEC-17保持OPEN。
