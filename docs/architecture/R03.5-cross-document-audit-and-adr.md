## 4. ADR摘要

### ADR-001 Modular Monolith + Independent Worker
MVP采用模块化单体和独立科学计算Worker，控制早期分布式复杂度并隔离计算资源。

### ADR-002 Model/Runtime/Renderer Separation
模型、执行生命周期和呈现职责分离，通过契约与Adapter交互。

### ADR-003 Declarative Immutable Experiment Package
实验包声明式、版本化、发布后不可变；依赖锁定和内容审核纳入发布流程。

### ADR-004 Runtime State Mutation Through Commands
所有Session状态变更经Command Handler；幂等、版本、事件、receipt和outbox同事务提交。

### ADR-005 Worker Fencing by Epoch
Worker结果匹配epoch、stateVersion、execution和lease，旧执行不能覆盖新状态。

### ADR-006 AI Through Tool Gateway
Agent不直接访问数据库、任意代码或设备控制接口。

### ADR-007 DC Circuit MVP; RC Circuit Technical Validation
教学与技术验证分离，避免技术案例反向扩大教学范围。
