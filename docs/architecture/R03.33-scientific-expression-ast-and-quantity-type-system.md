- 版本：0.1；日期：2026-11-02
- 状态：CI Run #81通过静态AST验证；未冻结DSL/单位库；未实现表达式求值器或Solver
- 关联：R03.9、R03.20（DEC-08/09/10/17）、R03.24、R03.29、R03.23

## 1. 目标与边界

为Scientific Model方程建立技术无关、可序列化、可静态验证的表达式树和物理量类型系统。AST只表达结构；静态检查器只推导类型/量纲并拒绝非法结构，不计算表达式结果、不执行用户代码、不选择求解器。

**非目标：** 生产表达式引擎、JIT/代码生成、任意脚本、自动微分、符号代数化简、数值求解器、第三方单位库选型。

## 3. Quantity、Unit、Dimension与Quantity Kind

- **Quantity**：带数值、unit_id和quantity_kind的量值；本契约不承诺数值执行。
- **Unit**：单位Registry条目，包含symbol、scale_to_si、offset_to_si及其dimension。
- **Dimension Vector**：四个SI基本维度指数，顺序严格继承R03.29。
- **Quantity Kind**：物理语义类别（如electric-potential、electric-current、electric-resistance、power、capacitance、time）；不能由dimension唯一推断。
- **Canonical Unit**：某quantity kind选定的规范表达单位。当前Registry中的V/A/ohm/W/F/s是本项目参考规范单位；完整canonical映射仍待注册表扩展。
- **Typed Expression**：静态推导出的dimension与quantity_kind，以及可选的目标类型约束。
- **Dimension Inference**：沿AST递归推导维度指数，乘法逐项相加、除法逐项相减、整数幂乘指数。

单位转换关系沿用R03.29：SI值 = value × scale_to_si + offset_to_si。带非零offset的单位不允许参与本版乘除、幂和函数运算；未来需先显式转换到线性单位。

## 4. AST节点契约

每个Expression包含expression_id、ast_version=1alpha1、root、expected_type和可选limits。节点使用严格判别字段kind：

- constant：value、unit_id、quantity_kind；值必须为有限JSON数值。
- symbol：symbol_id；只从注册表解析，禁止自由变量名。
- unary：positive/negate，单一operand。
- binary：add/subtract/multiply/divide/power，严格左右操作数。
- call：function与arguments；仅abs/sqrt/exp/log/sin/cos白名单，均为单参数。

比较与逻辑运算本版不纳入Scientific Equation AST：方程求解表达式必须产出Quantity；条件/事件谓词属于独立的Model Constraint/Runtime Event契约，避免混合布尔类型与物理量类型。后续确有需求再增加Boolean AST版本。

## 5. 静态类型与量纲规则

| 运算 | 约束 | 结果 |
|---|---|---|
| + / - | dimension与quantity_kind必须完全相同 | 保持左侧类型 |
| × | 两侧线性单位；维度指数逐维相加 | derived kind + 合成维度 |
| ÷ | 两侧线性单位；维度逐维相减 | derived kind + 合成维度 |
| 幂 | 指数必须是有界、无量纲整数常量；offset单位拒绝 | base dimension × exponent |
| negate/positive | 不改变类型 | 保持operand类型 |
| abs | 不改变类型 | 保持operand类型 |
| sqrt | 所有维度指数必须为偶数 | 指数逐维减半，kind=derived |
| exp/log/sin/cos | 输入必须无量纲 | dimensionless |

目标类型expected_type用于验证方程输出维度，并可对派生结果指定目标quantity_kind。维度相同不自动证明物理语义正确；Model方程声明的目标变量quantity_kind仍必须由模型层绑定检查。乘除的中间节点标记derived，禁止静态检查器凭维度猜测唯一物理语义。

## 6. 错误语义

至少稳定区分：SCHEMA_INVALID、UNKNOWN_SYMBOL、UNKNOWN_UNIT、QUANTITY_KIND_MISMATCH、DIMENSION_MISMATCH、EXPECTED_DIMENSION_MISMATCH、EXPECTED_QUANTITY_KIND_MISMATCH、UNREGISTERED_FUNCTION、UNSUPPORTED_OPERATOR、ARGUMENT_COUNT、DIVISION_BY_ZERO、NON_FINITE_NUMBER、NUMERIC_RANGE、INVALID_POWER、OFFSET_UNIT_UNSUPPORTED、DEPTH_LIMIT、NODE_LIMIT、ARGUMENT_LIMIT、UNKNOWN_NODE。

除零：静态阶段拒绝字面量零分母；涉及运行期变量的除数必须由未来执行器在求值前检查，不能宣称静态证明无除零。

NaN/Infinity：JSON解析和常量校验均拒绝；中间计算非有限值由未来数值执行器逐节点检查并返回确定错误，不允许写入Observation。

溢出：静态常量幅值设上限；未来执行器对每次算术结果检查有限性、范围及目标数值格式溢出。此静态验证器不执行运算，不能证明运行期无溢出。

## 7. 安全与资源边界

- 禁止eval、exec、动态import、任意Python/JavaScript/其他语言代码。
- AST节点不是源代码字符串，不允许解释为代码。
- 不存在任意函数名解析；仅显式白名单。
- symbol_id必须经Model变量/参数注册表解析。
- 默认最大深度32、节点512、函数参数8；Schema上限深度64、节点4096作为传输硬上限，验证器更严格。
- 常量绝对值默认上限1e100；整数幂绝对值不超过8。
- 禁止循环引用（JSON树结构本身不表达引用回边）；禁止未知字段和未知节点。
- 运行期仍需CPU/内存/时间预算；静态限制不等于执行沙箱。

## 8. 验证案例

正向：I=V/R、Req=R1+R2、P=V×I、dVc/dt=(Vs−Vc)/(R×C)。负向：异量纲加法、未知符号、未注册函数、不支持运算符、字面量除零、NaN/Infinity、深度/节点/参数超限、不合法幂、期望量纲不匹配、未知单位和offset单位。

RC导数示例的目标量纲为V/s = [1,2,-4,-1]。该Fixture只验证类型/量纲，不验证ODE正确性、初值、边界条件或求解器收敛。
