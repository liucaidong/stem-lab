1. Package Schema 的 `$id` 仍使用 `example.invalid` 占位域名，正式发布前必须替换为项目控制的稳定 URI。

7. Run #41/#42/#49/#53/#60/#62/#63/#65/#68/#70成功；Run #42/#49/#53/#60/#62/#63使用`requirements-contract-validation.lock.txt`固定直接及传递依赖版本。锁文件固定版本但尚未采用pip hash校验。Run #45–#48曾因OpenAPI value_ref块缩进错误而失败，修正后Run #49通过；失败和修复均保留在Git历史中。
