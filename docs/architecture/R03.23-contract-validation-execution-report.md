## 5. 当前发现与限制

1. Package Schema 的 `$id` 仍使用 `example.invalid` 占位域名，正式发布前必须替换为项目控制的稳定 URI。
2. `gradeBand.min` 与 `gradeBand.max` 的大小关系属于跨字段约束，当前 Schema 未表达；需由语义校验器处理，或在后续 Schema 设计中增加可表达的约束。
3. Schema 的 digest 正则仅验证字符串格式，不验证资源字节内容的 SHA-256。
4. Package 资源引用存在性、依赖锁、许可策略、签名、撤回状态和科学正确性不属于当前 JSON Schema 可独立证明的范围。
5. 本报告原始执行范围仅覆盖通用Event Envelope；R03.26后续新增SessionStarted、ExecutionSucceeded、ObservationRecorded三种Payload Schema/Fixture及Registry驱动验证，其他事件类型和Consumer幂等/乱序/重放测试仍未完成。
6. OpenAPI 若干响应只有 description，没有可供客户端生成和互操作测试使用的完整响应 Schema；认证、资源级授权、统一错误模型、分页边界和限流约束也未完整定义。
7. Run #41验证成功，但当时使用直接依赖固定、传递依赖由pip解析；随后新增全量版本锁文件并更新工作流，须以新的Run #42确认锁文件安装及完整回归。
