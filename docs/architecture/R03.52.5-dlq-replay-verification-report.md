## 4. What this does not prove

- No authentication or trusted authorization-decision issuer.
- No transactional lock/recheck of the source DLQ row.
- No new Job insertion, replay_count increment or immutable DB audit append.
- No request idempotency reservation under concurrency.
- No operator approval, break-glass or replay CLI.
- No real payload copy or execution.
- DEC-16 (ID strategy) and DEC-19 (tenant trust boundary) remain OPEN.

The function accepts an authorization decision as an input. It must not be mistaken for authentication or an independent security boundary.
