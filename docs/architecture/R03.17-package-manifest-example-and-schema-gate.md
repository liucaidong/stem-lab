# R03.17 Experiment Package Manifest样例与Schema冻结要求

- 版本：0.1；日期：2026-11-02
- 状态：示例草案；非正式JSON Schema
- 关联：R03.8、R03.10、R03.16

## 1. 目的

本文件给出可讨论的Manifest实例，帮助发现字段缺口。它不是正式Schema，也不应被运行时直接视为已批准契约。正式Schema必须由Schema工具生成验证器和兼容测试。

## 2. YAML样例

~~~yaml
apiVersion: stemlab.example/v1alpha1
kind: ExperimentPackage
metadata:
  id: org.example.dc-series-circuit
  version: 0.1.0
  title: DC Series Circuit and Ohm's Law
  description: Explore current and voltage in a simple series circuit.
  subject: physics
  gradeBand:
    min: null
    max: null
spec:
  learningObjectives:
    - id: objective-current-voltage-resistance
      statement: Relate current, voltage, and resistance using evidence.
  model:
    id: org.example.dc-series-model
    version: 1.0.0
    digest: sha256:REPLACE_WITH_REAL_DIGEST
  scene:
    id: org.example.dc-series-scene
    version: 1.0.0
    digest: sha256:REPLACE_WITH_REAL_DIGEST
  instruments:
    - id: org.example.voltmeter
      version: 1.0.0
      digest: sha256:REPLACE_WITH_REAL_DIGEST
    - id: org.example.ammeter
      version: 1.0.0
      digest: sha256:REPLACE_WITH_REAL_DIGEST
  workflow:
    id: org.example.dc-series-workflow
    version: 1.0.0
    digest: sha256:REPLACE_WITH_REAL_DIGEST
  assessment:
    rubric:
      id: org.example.scientific-reasoning-rubric
      version: 1.0.0
      digest: sha256:REPLACE_WITH_REAL_DIGEST
  runtime:
    allowedModes:
      - algebraic
    resetPolicy: restore-initial-state
    requiredCapabilities:
      - command-idempotency
      - observation-provenance
  assets: []
  validation:
    validationSuite: org.example.dc-series-reference-cases
    expertReviewRequired: true
~~~

示例中的命名空间、版本、摘要均为占位值。gradeBand为空不代表已决定适用年级；正式发布必须补齐经过审核的适用范围或明确标记不适用。

## 3. Schema规则草案

- apiVersion必须匹配平台支持的Package API版本；
- kind必须为ExperimentPackage；
- metadata.id在平台命名空间内唯一；
- metadata.version符合冻结的版本规范；
- title、subject、learningObjectives为必需；
- 所有依赖引用必须包含ID、版本和digest；
- 禁止latest、浮动分支、任意URL和本地路径引用；
- runtime.allowedModes必须是平台白名单；
- resetPolicy必须是受支持枚举；
- assets必须包含媒体类型、大小、digest、许可和来源元数据；
- validation必须引用可执行的验证套件和审批记录；
- 未知字段策略需明确：严格拒绝或兼容忽略，不能由不同服务各自决定。

## 4. 发布验证样例

DC Circuit Package发布前至少验证：
- Model存在且版本/digest固定；
- Scene中的元件ID与Model端口映射一致；
- 电压表/电流表绑定合法quantity；
- Workflow命令在Runtime白名单内；
- Rubric引用有效；
- 学习目标、适用年级和先修条件经审核；
- 所有Asset来源/许可可追溯；
- 科学参考算例通过；
- 内容安全扫描通过；
- 审核记录和发布主体可追溯。

## 5. 正式Schema冻结交付

1. JSON Schema文件和版本策略；
2. Schema validator及错误路径格式；
3. 正/负向样例集；
4. 兼容性测试与迁移策略；
5. 规范化序列化和digest算法；
6. Package签名/来源证明；
7. Package Resolver实现契约；
8. 旧版本支持窗口和撤回规则。

正式Schema必须进入版本控制并通过CI验证；本样例不得作为绕过该流程的生产输入。
