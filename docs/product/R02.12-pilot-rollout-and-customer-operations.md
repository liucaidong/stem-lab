# R02.12 试点部署、客户成功与产品运营方案

- 版本：0.1；日期：2026-11-02
- 状态：运营方案草案；目标市场和试点机构未确定
- 关联：R02.5、R02.7、R02.10、R02.11、R03.12

## 1. 目标

定义从内部验证到受控课堂试点的运营路径。试点必须同时验证产品价值、教师采用、学生体验、技术可靠性、内容质量和数据治理；不是简单开放账号。

## 2. 试点阶段

### Pilot 0 — 内部质量验证
参与者：产品、工程、科学专家和教学设计人员。
目标：验证科学正确性、核心流程、数据追溯、异常恢复和内容发布治理。
退出条件：P0端到端验收和安全/可靠性阻断项通过。

### Pilot 1 — 教师可用性验证
参与者：少量目标教师，使用合成或脱敏数据。
目标：验证备课、布置、审阅和反馈工作流。
退出条件：关键教师任务可完成；高严重度体验问题有修复计划。

### Pilot 2 — 小规模课堂试点
参与者：经机构批准的教师和学生班级。
目标：验证课堂时间、学生理解、操作成功、数据完整和教师负担。
前置：适用法律/隐私评估、必要授权、数据处理协议、支持与事故响应准备。
退出条件：无未关闭的严重安全或科学问题；数据足以支持下一轮决策。

### Pilot 3 — 多班级/多机构验证
目标：验证机构部署、身份集成、容量、支持成本和可重复交付。
退出条件：服务质量、成本、内容运营和客户成功流程达到批准门槛。

## 3. 试点前置检查

- 目标、假设、成功/失败标准明确；
- 参与机构、年级、课程和教师责任明确；
- 参与者授权和隐私通知按适用要求完成；
- 数据字段、访问角色、保留、删除和导出策略确认；
- Package和Model版本固定；
- 教师培训材料和学生操作说明准备；
- 浏览器、设备和网络条件验证；
- 支持渠道、责任人和事故升级路径明确；
- 暂停、退出和数据处理流程演练。

## 4. 入驻与培训

教师培训覆盖课程/班级建立、任务配置、Rubric理解、学生引导、报告审阅、数据导出和问题上报。学生引导覆盖实验目标、仪器含义、操作控制、数据记录、错误恢复和安全规范。管理员培训覆盖Tenant、SSO/LTI（若启用）、Roster、角色映射、数据策略、配额、审计和支持流程。

培训不应要求教师掌握内部Runtime或模型工程术语。

## 5. 客户成功工作流

Onboarding：目标确认、技术接入、角色配置和教师培训。
Activation：首个课程/实验成功启动。
Adoption：持续使用、教师审阅和学生提交。
Value Review：学习证据、教师效率、系统稳定性和成本。
Renewal/Expansion：基于数据和反馈讨论续用及扩展。
Support：问题分级、响应、修复、复盘和知识库。

登录次数不能替代真实课堂采用；平台停留时间不能简单视为学习质量。

## 6. 运营指标

| 维度 | 指标 | 采集方式 |
|---|---|---|
| 激活 | 首个Assignment发布率、首个Session成功率 | 产品事件和运营记录 |
| 采用 | 活跃课程、实验完成、教师复用 | 按机构/课程分层 |
| 学习 | 概念测验、论证Rubric、数据解释质量 | 课程评估工具 |
| 教师效率 | 备课/审阅耗时 | 任务观察和问卷 |
| 可靠性 | 启动成功率、失败恢复、错误率 | 技术遥测 |
| 内容质量 | Package缺陷、审核周期、撤回次数 | 内容治理系统 |
| 经济性 | 每Session成本、支持工时、部署成本 | 财务/运维数据 |
| 信任 | 权限事件、隐私请求、投诉和事故 | 安全审计 |

## 7. 支持与事故分级

- SEV-1：跨租户数据泄露、重大科学错误、学生数据暴露或全体试点不可用；立即暂停受影响功能并启动事故流程。
- SEV-2：关键实验无法完成、广泛数据不一致或成绩错误；停止扩展，优先修复并通知负责人。
- SEV-3：局部功能故障且存在替代路径；记录并排期修复。
- SEV-4：一般体验问题和建议；进入产品反馈队列。

事故复盘包含时间线、影响范围、根因、数据处理、沟通、修复和防复发措施。

## 8. 试点决策报告

每轮试点输出目标和参与者结构、设备/网络/课程条件、关键任务结果、失败类型、学习证据及局限、教师时间成本、技术可靠性、单位成本、安全事件、支持负担、内容缺陷，以及继续/调整/扩展/终止的决策理由。

## 9. 退出与数据处理

试点终止时撤销账号和集成凭证，按协议导出机构所需数据，执行保留/删除策略，关闭外部访问，归档审计记录并确认对象存储和备份生命周期。不得因试点结束而忽略合同或法律保留要求，也不得无限期保留非必要数据。

## 10. 未决事项

目标市场、试点机构、学生年龄/年级、课程标准、部署区域、支持时段、合同责任和数据保留期限待决策。本文不代表已与任何学校或机构达成试点合作。
